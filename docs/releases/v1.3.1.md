# Cuphead Input Display v1.3.1

## True per-pixel transparent window

In **Layout Settings → Cuphead Input Display → General**:

1. Enable **Show display in a separate window**.
2. Enable **Transparent window background**.

The display uses native per-pixel alpha—not chroma key. Empty areas are completely transparent; black artwork remains visible, and anti-aliased edges and soft shadows retain partial transparency.

Transparent mode hides the title bar and ignores the component's background color/image without deleting their settings. Drag a visible input sprite to move the window. Turn transparency off to restore the saved title-bar and background settings.

The inline display keeps its opaque background. All settings remain native LiveSplit controls; the component remains a single DLL under **Other**.

**163 checks pass**, including successful Windows layered-window presentation, zero-alpha background pixels, opaque black artwork, partial-alpha edges/shadows, premultiplied pixel data, and switching between titled, borderless, opaque and transparent windows.
