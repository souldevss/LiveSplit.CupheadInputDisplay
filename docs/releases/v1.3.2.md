# Cuphead Input Display v1.3.2

- Replaced the standard Windows color dialog with **LiveSplit's own color picker**, including its screen eyedropper.
- To sample the screen: hold the eyedropper button, drag to the desired color, then release and confirm with OK.
- Color swatches are now fixed at **23×23 pixels**, with a separate hex label and Choose button.
- Background-image selection now uses a compact thumbnail button and LiveSplit-style image file dialog.
- Color changes apply to the component, and Cancel restores the previously accepted color.

**170 checks pass.** Tests open the real LiveSplit color dialog, verify its eyedropper control, apply a color, check the saved value/swatch/hex label, cancel a second change, and verify compact swatch/image-thumbnail sizes. Existing rendering, background-image, separate-window and per-pixel transparency checks continue to pass.

Close LiveSplit before replacing Components/LiveSplit.CupheadInputDisplay.dll. The picker uses libraries already shipped with LiveSplit; no additional component files are installed.
