# Cuphead Input Display v1.2.1

Download **LiveSplit.CupheadInputDisplay.dll**, close LiveSplit, and put the DLL in its **Components** folder. No asset directory is needed.

Add it from **Edit Layout → + → Information → Cuphead Input Display**. Configure it through the native **Layout Settings** tab.

- Always-on character, plane and in-game control detection.
- Fully opaque solid background colors, including a green-screen preset.
- Config tab removed; no gradients, transparent-background option or WebView.
- Dark inactive / bright pressed defaults, inversion, separate 0–100% color strengths and per-element colors.
- Custom borders and soft drop shadows with cached rendering.
- Live-input previews by default. Preview-only states are isolated from real input data and use the same renderer.

Validated with **105 checks**, including pixel-exact preview/display comparisons. Read-only live game checks reported Cuphead / Plane and a resolved input table. Physical controller presses and Ms. Chalice were not observed in that live check.

The existing LiveSplit installation must already include the Cuphead memory-reader DLL and SharpDX dependencies described in the README.
