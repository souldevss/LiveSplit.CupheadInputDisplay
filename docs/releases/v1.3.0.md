# Cuphead Input Display v1.3.0

Close LiveSplit and replace **Components/LiveSplit.CupheadInputDisplay.dll**, then reopen it.

## Separate display window

Open **Layout Settings → Cuphead Input Display → General** and enable **Show display in a separate window**.

- Uses zero height/width in the splits layout, keeping the splits compact.
- Includes window width/height, always-on-top and show-title-bar settings.
- Remembers window position and size in the layout.
- Drag the background to move a borderless window.
- Closing the window returns the input display to the layout.
- Recovers an off-screen saved position onto an available monitor.
- Uses the same live input, character/plane detection, background image and styling renderer.

All settings remain inside LiveSplit Layout Settings. The component remains a single DLL under **Other**.

**151 checks pass**, including separate-window lifecycle, zero layout footprint, settings persistence, geometry, borderless/topmost options, off-screen recovery and exact renderer matching.
