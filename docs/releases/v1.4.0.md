# Cuphead Input Display v1.4.0

- Optional **Star Skip on win screen (Z / A)** in General, off by default.
- Detects Cuphead's `scene_win` using the installed autosplitter's scene reader. Only the star appears on that screen; normal inputs return afterward.
- Fixed keyboard Z / controller A input, independent of jump bindings.
- One static star sprite. Animation code and unused frames have been removed. The installed component remains one DLL, approximately 686 KiB, with no benchmark tools included.
- Independent inactive and pressed colors, native color picker with eyedropper, Original/Multiply/Colorize/Solid modes, color strength and brightness. Defaults retain the original gold artwork.
- The star stays small and centered, with adjustable size and position.
- Dedicated **Star Skip** settings tab with separate **Appearance**, **CPS**, **Layout** and **Effects** sections, independent borders/shadow and a preview that works outside Cuphead. Normal-input settings do not affect Star Skip, and Star Skip settings do not affect normal inputs.
- Added a rolling one-second CPS counter beside the star, with independent text color, size, visibility and right/below placement. Held inputs do not repeat; the count resets when leaving results. Preview testing has its own counter.
- Added independent **Scale on press** and **Pressed size (%)** controls to Star Skip Appearance. CPS text stays steady while the star scales.
- Settings previews do not alter the live win-screen detection or enable the feature automatically.
- Optimized rendering and memory polling: removed per-draw JSON serialization, string cache keys, repeated numeric parsing, artwork-path allocations and reflection discovery, and reused scalar memory-read buffers.

**225 checks pass**, covering static artwork, separate colors/strength/brightness, saved settings, native controls, preview rendering outside the game and exclusive win-screen visibility. Win-screen switching has not yet been observed live in a running game.

This replaces the earlier build of **1.4.0** and retains that version number. Artwork by StudioMDHR, ripped by RavenclawNimbus, from The Spriters Resource. Close LiveSplit before replacing Components/LiveSplit.CupheadInputDisplay.dll.
