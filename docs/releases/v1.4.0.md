# Cuphead Input Display v1.4.0

- Added optional **Star Skip on win screen (Z / A)** in General, off by default.
- Detects Cuphead's `scene_win` through the installed autosplitter's scene reader. On that screen, only the star is shown; normal inputs return when leaving it.
- Fixed input: keyboard Z or controller A, independent of jump bindings.
- Each new press plays the original eight-frame appearing animation, then returns to the three-frame main idle loop. A held button does not restart it, and a quick tap finishes it.
- Uses the provided win-screen artwork, with all 11 animation frames embedded in the same DLL. Idle artwork is centered on the appearance canvas to keep alignment stable.
- Layout controls support the star's visibility, size, position and custom colors; global pressed/inactive colors, borders and shadows also apply.

**225 checks pass**, including scene visibility transitions, exclusive star rendering, all animation frames, held/tapped inputs, saved settings and native UI controls. Win-screen switching has not yet been observed live in a running game.
