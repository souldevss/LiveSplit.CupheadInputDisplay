# Cuphead Input Display v1.4.0

- Added optional **Star Skip on win screen (Z / A)** in General, off by default.
- Detects Cuphead's `scene_win` through the installed autosplitter's scene reader. On that screen, only the star is shown; normal inputs return when leaving it.
- Fixed input: keyboard Z or controller A, independent of jump bindings.
- Each new press plays the original eight-frame appearing animation, at approximately 24 fps (0.33 seconds), then returns to the three-frame main idle loop. A held button does not restart it, and a quick tap finishes it.
- Uses the provided win-screen artwork, with all 11 animation frames embedded in the same DLL. Idle artwork is centered on the appearance canvas to keep alignment stable.
- The star is small and centered instead of stretching to fill the display. Layout controls support visibility, size and position. Original sprite colors are always preserved; display coloring and effects do not alter the star.

**228 checks pass**, including scene visibility transitions, exclusive star rendering, all animation frames, held/tapped inputs, saved settings and native UI controls. Win-screen switching has not yet been observed live in a running game.

Artwork by StudioMDHR, ripped by RavenclawNimbus, from The Spriters Resource. Close LiveSplit before replacing Components/LiveSplit.CupheadInputDisplay.dll.

This replaces the initial 1.4.0 build with corrected star size, original colors and a twice-as-fast appearance animation. The version remains 1.4.0.
